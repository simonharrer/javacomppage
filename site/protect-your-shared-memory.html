Protect Your Shared Memory 

class Counter {

    private long count;

    void increment(long amount) {
        if (amount < 1) {
            throw new IllegalArgumentException("Only positive increments!");
        }

        this.count += amount;
    }
}
  • shared memory, unprotected
  • what can happen here when two threads count 100 times: expected 200, but basically any value could happen
  • reading and writing 64 bit is not atomic, only 32 bit is
  • lost updates
var tmp = count; // read
var tmp = tmp + 1; // update
count = tmp; // write

class Counter {

    private long count;

    synchronized void increment(long amount) {
        if (amount < 1) {
            throw new IllegalArgumentException("Only positive increments!");
        }

        this.count += amount;
    }
}
