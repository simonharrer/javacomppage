Become a Better Java Developer in 70 Examples

A Mentor for you

This book is a useful companion for anyone learning to write clean Java code. The authors introduce you to the fundamentals of becoming a software developer, by comparing pieces of problematic code with an improved version, to help you to develop a sense for clean code. This unique before-and-after approach teaches you to create clean Java code.

Code Cleanly

Keep your booleans in check, get rid of magic numbers, and use the right style of iteration. Comment wisely, name things accurately, handle exceptions robustly, test with JUnit 5, and write elegant functional and object-oriented code.

Become a Developer

Writing excellent code isn’t just about implementing the functionality. It’s about the small important details that make your code more readable, maintainable, flexible, robust, and faster. Java by Comparison teaches you to spot these details and trains you to become a better programmer.

Who Is This Book For?

For anyone learning to program in Java at a beginner or intermediate level, and for teachers and senior developers who coach new developers.

Before reading

  • You know the Java basics: conditions, loops, classes and objects, simple algorithms, and lists, queues, stacks and maps.
  • You can solve FizzBuzz in Java. That is the readiness check from the preface.
  • Your code works, but you are not sure it is clean, readable, and easy to maintain.

After reading

  • You spot common code smells in booleans, formatting, magic numbers, and iteration.
  • You name things right, comment wisely, and handle exceptions robustly.
  • You test with JUnit 5 and use a functional style and clear object-oriented design.
  • You have internalized a checklist of 70 items to review your own and others' code.

Already know Effective Java and Clean Code? You will still find something new. All you need is a Java 8 compiler, a text editor, and a fresh mind. For newer Java, up to Java 25, see the free Modern Java and Java Concurrency comparisons.

The Science Behind the Book: Teaching Clean Code

The before/after method was developed and evaluated in university teaching and published in peer-reviewed software engineering education workshops. Read the story of the book and the research behind it.

  • Teaching Clean Code

    Linus W. Dietz, Johannes Manner, Simon Harrer, Jörg Lenhard. ISEE 2018 at SE 2018, Ulm. CEUR Workshop Proceedings Vol. 2066, pp. 24–27.

    Describes a feedback-driven course for 2nd and 3rd year students that puts clean code ahead of mere correctness, refined over more than six years and awarded a faculty teaching award. It proposes a knowledge base of before/after examples, the idea behind this book.

  • Code Process Metrics in University Programming Education

    Linus W. Dietz, Robin Lichtenthäler, Adam Tornhill, Simon Harrer. ISEE 2019 at SE 2019, Stuttgart. CEUR Workshop Proceedings Vol. 2308, pp. 23–26.

    Mines the Git repositories of 38 student teams in two Bamberg courses that use Java by Comparison in their code reviews, and analyzes how code process metrics relate to students' grades.

Frequently Asked Questions

What is Java by Comparison?

Java by Comparison: Become a Java Craftsman in 70 Examples is a book by Simon Harrer, Jörg Lenhard, and Linus Dietz, published by The Pragmatic Bookshelf in 2018. Each of its 70 items compares a piece of flawed Java code with an improved version and explains the difference.

Who should read Java by Comparison?

Developers learning Java at a beginner or intermediate level who already know the basics such as conditions, loops, classes, and collections. Teachers and senior developers use it as a reference when reviewing code of students and junior developers.

What topics does the book cover?

Booleans and conditions, formatting, magic numbers, iteration, comments, naming, exception handling, testing with JUnit 5, functional programming with lambdas and streams, object-oriented design, and preparing code for the real world with static analysis, build automation, and concurrency.

How is it different from Clean Code or Effective Java?

It is shorter and example-driven: every item shows a concrete piece of code before and after the improvement, so you can apply it right away. Readers who already know Clean Code and Effective Java still find new items.

Which Java version does the book use?

The examples need a Java 8 compiler and use lambdas, streams, and JUnit 5. The advice applies to newer Java versions as well.

Where can I buy it?

As an e-book (PDF, EPUB, MOBI) and paperback from The Pragmatic Bookshelf, and as a paperback on Amazon in the US, UK, and Germany. A Korean translation was published by Gilbut in 2020.

Is there a free sample?

Yes. The preface and three complete items are free PDFs: Return Boolean Expressions Directly, Document Using Examples, and Split Method with Boolean Parameters. They are linked in the table of contents on this page.
