Teaching with the Book

Java by Comparison was born in the classroom. Today, universities, companies, and study groups use it to teach clean Java code.

How to Teach with Java by Comparison

  • Grade with code reviews. Point students to the matching item instead of writing the same explanation again. Each item shows the problem and the solution side by side, so students understand why.
  • Accompany any programming course. Once students know basic Java syntax, the book fits basically any course with programming tasks. A FizzBuzz exercise is a good readiness check.
  • Run the kata. The Java by Comparison kata is a two-hour exercise for pairs, with code, tests, and a checklist on GitHub.
  • Play Comparison Jeopardy. In the game, students find the name of a comparison, which trains their naming skills.
  • Start with the free material. The preface and three items are free samples, and all 70 comparisons are listed online.

The concept behind it is described in our research and in the story of the book.
